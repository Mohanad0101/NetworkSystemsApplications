# Сетевые системы и приложения

Интерактивный университетский практикум: Windows PC → Oracle VirtualBox → Linux Mint 22.3 “Zena”.

## Что изучают студенты
Курс ведёт от подготовки Linux VM и уверенной работы в shell к SSH, правам доступа, процессам, systemd, файловым системам и Bash-автоматизации. Каждая лабораторная сочетает короткие веб-слайды, объяснение концепций, практические действия, проверяемые результаты, формативные MCQ и DOCX-отчёт.

## Лабораторные
- LX0 — учебная Linux VM и базовая сеть
- LX1 — shell, файловая система, перенаправления и ссылки
- LX2 — SSH из Windows PowerShell в Mint VM
- LX3 — пользователи, группы и права
- LX4 — процессы и сигналы
- LX5 — systemd и журнал
- LX6 — image, loop, ext4 и mount
- LX7 — Bash-автоматизация

## Среда
Студенту не требуется административная учётная запись Windows для обычной работы курса. VirtualBox предполагается установленным/управляемым преподавателем или ИТ-службой. Linux-административные действия выполняются внутри учебной Mint VM.

## Взаимодействие
В каждой лабораторной есть короткий peer troubleshooting/review момент. Конкретный канал общения задаёт преподаватель или LMS. Репозиторий не отправляет студенческие данные во внешние сервисы автоматически.
