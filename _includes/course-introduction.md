<h3 id="why-linux">Зачем разработчику Linux</h3>

Написать программу — первый шаг. Чтобы она работала для пользователей, нужно подготовить окружение, настроить доступ и сеть, уметь найти причину сбоя. **Linux помогает понять, что происходит с приложением после запуска:** какие файлы оно использует, от чьего имени работает и как обменивается данными.

Эти навыки нужны в серверной и веб-разработке, тестировании, DevOps, администрировании и работе с данными. На практике вы будете читать журналы ошибок, проверять соединения и автоматизировать повторяющиеся действия. Работать над кодом можно и в Windows; знание Linux позволяет уверенно обращаться с серверной средой.
> **Вход в курс.** Для LX0–LX5 достаточно уверенно пользоваться компьютером и выполнять инструкции: эти работы специально вводят Linux с нуля. Для последующих тем сетевого программирования понадобятся базовые знания Python и компьютерных сетей, как указано в исходной программе курса.

Подробнее: [Linux и его применение](https://www.redhat.com/en/topics/linux/what-is-linux), [Ubuntu Server](https://ubuntu.com/server).

<h3 id="concepts">Linux: основные понятия перед стартом</h3>

**Операционная система** управляет процессами, памятью, устройствами и данными. **Ядро Linux** — её центральная часть. Ядро вместе с системными утилитами, менеджером пакетов и приложениями образует **дистрибутив** — готовую к установке систему.

**Терминал** — окно для текстового ввода и вывода. **Bash** — командная оболочка, которая выполняет команды и сценарии. В терминале Linux Mint мы будем работать с Bash.

#### Рабочая станция и сервер

Рабочая станция предназначена прежде всего для работы человека: графический стол, браузер, редактор. Сервер предоставляет услуги другим программам и компьютерам; им часто управляют по SSH без графического стола. **Клиент** отправляет запрос, **сервер** обрабатывает его и отвечает. Это роли: на настольном Linux тоже можно запустить серверное приложение.

| Семейство | Рабочая станция | Сервер | Пакеты |
|---|---|---|---|
| **Debian / Ubuntu** | Debian, Ubuntu Desktop; Linux Mint — удобная настольная система на основе Ubuntu, LMDE — на основе Debian | Debian, Ubuntu Server | DEB, APT |
| **Fedora / Red Hat** | Fedora Workstation | Fedora Server; RHEL — корпоративная система с длительной поддержкой | RPM, DNF |

В курсе используем **Linux Mint Cinnamon**. Его привычный рабочий стол помогает освоиться, а навыки работы с файлами, процессами, правами и сетью пригодятся и в других дистрибутивах. Источники: [Linux Mint](https://linuxmint.com/about.php), [Debian](https://www.debian.org/intro/about), [Fedora](https://fedoraproject.org/), [Fedora и RHEL](https://docs.fedoraproject.org/en-US/quick-docs/fedora-and-red-hat-enterprise-linux/).

#### Linux и Windows: что меняется в повседневной работе

Обе системы подходят для разработки. В лабораторных обратите внимание на несколько различий:

| Действие | Linux Mint | Windows |
|---|---|---|
| Найти файл | Единое дерево от `/`, домашний каталог `/home/имя` | Пути с буквами томов, например `C:\Users\имя` |
| Указать имя | На обычной ext4 `Report.txt` и `report.txt` — разные файлы | В типичной настройке регистр имён не различается |
| Установить приложение | Менеджер программ и APT, пакеты из репозиториев | Microsoft Store, установщики, WinGet |
| Автоматизировать работу | Bash и другие оболочки | PowerShell и другие средства |
| Повысить права | Отдельные команды через `sudo` | Повышение прав через UAC |

Приложению нужна версия для выбранной ОС или подходящий способ совместимого запуска: копирование `.exe` не превращает его в Linux-программу. [Сравнение файловых систем](https://learn.microsoft.com/en-us/windows/wsl/filesystems) · [WinGet](https://learn.microsoft.com/en-us/windows/package-manager/winget/) · [UAC](https://learn.microsoft.com/en-us/windows/security/application-security/application-control/user-account-control/).
